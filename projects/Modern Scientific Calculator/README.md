# ⚡ Modern Scientific Calculator

A premium **Scientific Calculator** built with **HTML, CSS, and JavaScript** featuring a modern black glassmorphism interface, multiple mathematical operations, calculation history, responsive design, keyboard shortcuts, and Local Storage support.

# 📖 How to Use

### Step 1

Enter the first number.

### Step 2

Enter the second number.

*(Not required for Square Root and Cube.)*

### Step 3

Choose an operation from the dropdown.

### Step 4

Click **Calculate** or press **Enter**.

### Step 5

View the result instantly.

# 📜 Calculation History

Every successful calculation is automatically saved.

Example:

```text
12 + 8 = 20

45 × 2 = 90

√81 = 9

2 ^ 10 = 1024
```

History is stored in **Local Storage**, so it remains available even after refreshing the page.
