# 🎓 Student Grade Calculator

A simple Student Grade Calculator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Calculate total marks
- Calculate percentage
- Automatic grade generation
- Pass/Fail status
- Input validation
- Responsive UI
- Modern design
