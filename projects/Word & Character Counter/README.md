# Word & Character Counter

A modern **Word, Character, and Sentence Counter** web application built with HTML, CSS, and JavaScript.

The application counts text statistics instantly while typing and provides a clean dark UI experience.

---

## Features

✨ Real-time word counting  
✨ Real-time character counting  
✨ Sentence counting  
✨ Detects sentences ending with:
- `.`
- `?`
- `!`

✨ Modern black UI theme  
✨ Responsive design for mobile and desktop  
✨ Simple and fast performance  
✨ No external libraries required  

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## How It Works

1. Enter or paste your text into the text box.
2. The application automatically calculates:
   - Total words
   - Total characters
   - Total sentences
3. Results update instantly while typing.
