A modern, responsive, and feature-rich **Temperature Converter** built using **HTML, CSS, and JavaScript**. Convert temperatures instantly across multiple temperature scales with a beautiful glassmorphism interface, live conversion, and a clean user experience.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/probal2005/Multi-Temperature-Converter.git
```

## Navigate to the Project

```bash
cd Multi-Temperature-Converter
```

## Run

Simply open **index.html** in your favorite web browser.

No installation required.

---

# 📖 How to Use

1. Open the application.
2. Enter a value in **any** temperature field.
3. All remaining temperature units update automatically.
4. Click **Copy Values** to copy all converted results.
5. Click **Reset** to restore default values.

# ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
