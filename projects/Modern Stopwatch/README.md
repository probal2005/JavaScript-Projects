## 📖 How to Use

1. Click **Start** to begin the stopwatch.
2. Click **Stop** to pause the timer.
3. Click **Reset** to reset the timer to `00:00:00:00`.
4. Use the keyboard shortcuts for faster control:
   - **Space** → Start / Stop
   - **R** → Reset
