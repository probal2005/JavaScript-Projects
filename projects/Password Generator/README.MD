# 🔐 Password Generator

A modern and responsive **Password Generator** built using **HTML, CSS, and JavaScript**. Easily generate strong and secure passwords with customizable options such as uppercase letters, lowercase letters, numbers, and symbols.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/probal2005/Password-Generator.git
```

### Open the project

Simply open **index.html** in your favorite web browser.

---

## 📖 How to Use

1. Choose the password length.
2. Select the character types:
   - Uppercase
   - Lowercase
   - Numbers
   - Symbols
3. Click **Generate Password**.
4. Click the **Copy** button to copy the generated password.
