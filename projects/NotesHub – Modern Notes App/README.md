# 📝 NotesHub – Modern Notes App

A modern **Notes Management Application** built with **HTML, CSS, and JavaScript** featuring a premium glassmorphism dark interface, note pinning, search, export, Local Storage, responsive design, and a beautiful user experience.

# 📖 How to Use

## Create Note

- Click **Add Note**
- Enter title
- Enter description
- Select color
- Pin note (optional)
- Click **Save**

---

## Search

Use the search box to instantly filter notes.

---

## Pin Note

Click the 📌 icon to keep important notes at the top.

---

## Export Notes

Click **Export** to download all notes as a `.txt` file.

---

## Delete

Delete individual notes or remove all notes using **Clear All**.

---

# ⌨ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl + Enter | Save Note |

# 💾 Local Storage

All notes are automatically saved in your browser.

No backend or database is required.

Even after refreshing the page, your notes remain available.

---

# 📦 Data Structure

Each note is stored as an object.

```javascript
{
    id: 172304521,
    title: "Shopping",
    content: "Buy Milk",
    color: "#6366F1",
    pinned: false,
    date: "July 26, 2026"
}
```
