# 🧮 Modern Glassmorphism Calculator

A beautiful, responsive, and modern calculator built using **HTML, CSS, and JavaScript**. This project features a glassmorphism-inspired user interface, animated gradient background, keyboard support, and a clean user experience.

## ✨ Features

- 🎨 Modern Glassmorphism UI
- 🌈 Animated Gradient Background
- 📱 Fully Responsive Design
- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 📊 Percentage
- 🔢 Decimal Support
- ⌫ Backspace
- 🧹 All Clear (AC)
- ⌨ Keyboard Support
- ⚡ Smooth Button Animations
- ❤️ Beautiful Footer
- 💻 Lightweight & Fast

## ⌨ Keyboard Shortcuts

| Key | Action |
|------|--------|
| 0-9 | Numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Percentage |
| . | Decimal |
| Enter | Calculate |
| Backspace | Delete Last Character |
| Delete | Clear Display |
