# 🐞 Issue Tracker Pro

A modern and responsive **Issue Tracker** built using **HTML, CSS, JavaScript, Bootstrap, jQuery, and LocalStorage**. It helps developers create, manage, search, filter, and organize project issues with an elegant glassmorphism interface.

---
