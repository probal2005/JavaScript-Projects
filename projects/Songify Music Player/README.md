## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/probal2005/Songify-Music-Player.git
```

### Open the Project

Simply open **index.html** in your favorite web browser.

> **Note:** Ensure that your `songs.js` file, `images` folder, and audio files are correctly linked for the player to work as expected.

---

## 🎼 How to Use

1. Open the application.
2. Select a song from the playlist.
3. Click the **Play** button.
4. Use **Previous** and **Next** controls to navigate songs.
5. Click the progress bar to seek through the track.
6. Switch between **Repeat**, **Repeat One**, and **Shuffle** modes.
7. Mute or unmute audio using the volume button.
