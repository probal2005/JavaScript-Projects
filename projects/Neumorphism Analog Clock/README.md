# 🕒 Neumorphism Analog Clock

A beautiful and responsive **Neumorphism Analog Clock** built using **HTML, CSS, and JavaScript**. This project combines a classic analog clock with a modern digital display, dark/light mode, smooth animations, and an elegant neumorphic user interface.

# ✨ Features

## 🎨 User Interface

- 🎨 Modern Neumorphism Design
- 🌙 Dark & Light Theme
- ✨ Smooth Animations
- 📱 Fully Responsive
- 💎 Elegant Shadows
- ❤️ Professional Footer
- 🖱️ 3D Tilt Effect (VanillaTilt)

## 🕒 Clock Features

- 🕒 Live Analog Clock
- 💻 Live Digital Clock
- 📅 Current Date
- 🌍 Automatic Timezone Detection
- ⏱️ Real-Time Second Hand
- ⚡ High Accuracy

---

## 🌙 Theme Features

- Light Mode
- Dark Mode
- Theme Memory using Local Storage
- Keyboard Shortcut (**T**) to switch theme

- Fast Loading
- Pure JavaScript
- No Backend Required
