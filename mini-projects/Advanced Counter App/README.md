# 🚀 Advanced Counter App

A modern and interactive **Advanced Counter App** built using **HTML, CSS, and JavaScript**. This project goes beyond a basic counter by offering multiple controls, live statistics, keyboard shortcuts, automatic data saving, and a beautiful glassmorphism user interface.

# ✨ Features

## 🎯 Counter Functions

- ➕ Increase Counter
- ➖ Decrease Counter
- 🔄 Reset Counter
- ➕ Increase by 5
- ➖ Decrease by 5
- 🎲 Generate Random Number

---

## 📊 Statistics

- 📈 Highest Value
- 📉 Lowest Value
- 👆 Total Button Clicks

---

## 💾 Data Storage

- 💾 Automatically saves data
- 🔄 Restores data after page refresh
- ⚡ Uses Local Storage

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| ↑ | Increase |
| ↓ | Decrease |
| R | Reset |

---

## ⏰ Extra Features

- 🕒 Live Digital Clock
- 🎉 Milestone Celebration (100, 500, 1000)
