# ⏰ Glowing Digital Clock

A modern and responsive **Glowing Digital Clock** built with **HTML, CSS, and JavaScript**. The clock displays the current time with milliseconds and updates in real time with a beautiful glowing effect.

---

## 🎯 How It Works

- Uses JavaScript's `Date()` object to get the current system time.
- Updates automatically using `setInterval()`.
- Formats the time into a 12-hour clock with AM/PM.
- Displays milliseconds for a smooth digital clock experience.
- Styled with CSS for a glowing neon effect.
