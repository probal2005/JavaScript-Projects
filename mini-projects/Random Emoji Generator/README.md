# 😀 Random Emoji Generator

A fun and interactive **Random Emoji Generator** built using **HTML, CSS, and JavaScript**. Generate over **120+ emojis** with smooth animations, colorful neon glow effects, and a modern glassmorphism interface.


## 🎯 How It Works

- Loads a collection of 120+ emojis.
- Randomly selects an emoji.
- Prevents the same emoji from appearing twice consecutively.
- Plays a smooth pop animation.
- Applies a random neon glow color every time.
- Supports mouse clicks and keyboard interaction.
