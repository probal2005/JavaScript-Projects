# 📖 Country Lookup

A simple and responsive web application that allows users to search for any country and view information retrieved from the **Wikipedia REST API**.

Built with **HTML5**, **CSS3**, **Bootstrap 5**, and **Vanilla JavaScript**.

---

## 🚀 Features

- 🔍 Search any country by name
- 📖 Fetch country information from Wikipedia
- 🖼️ Display country image (if available)
- 📝 Read a short country description
- 🔗 Direct link to the full Wikipedia article
- ⚡ Fast and lightweight
- 📱 Fully responsive design
- ❤️ Professional footer with author credits

---

## 🌍 How It Works

1. Enter the name of a country.
2. Click the **Search** button or press **Enter**.
3. The application requests data from the Wikipedia REST API.
4. The country's summary, image, and article link are displayed.

---

## 📡 API Used

Wikipedia REST API

```
https://en.wikipedia.org/api/rest_v1/page/summary/{country-name}
```

Example:

```
https://en.wikipedia.org/api/rest_v1/page/summary/India
```
